# Projet de Cryptographie en JavaScript

Ce projet est une série d'exercices en JavaScript qui implémentent différentes fonctionnalités liées à la cryptographie, notamment le chiffrement et le déchiffrement César, ainsi que des outils pour manipuler des chaînes de caractères.

---

## Fonctionnalités implémentées

### Partie 1 : What are words worth ?
- **Fonction `what_are_words_worth()`** : Demande une entrée à l'utilisateur, calcule sa longueur, et demande une confirmation.

### Partie 2 : Count Wordula
- **Fonction `count_words(string_of_words)`** : Compte le nombre de mots dans une phrase.

### Partie 3 : Count Wordula, 2nd of his name
- **Fonction `count_words_by(string_of_words, separator)`** : Compte le nombre de mots en utilisant un séparateur personnalisé.

### Partie 4 : Des chiffres & des lettres : voyelles
- **Fonction `count_vowels(string_of_words)`** : Compte le nombre de voyelles dans une phrase.
- **Fonction `is_a_vowel(letter)`** : Vérifie si une lettre est une voyelle.

### Partie 5 : Des chiffres & des lettres : consonnes
- **Fonction `count_consonants(string_of_words)`** : Compte le nombre de consonnes dans une phrase.

### Partie 6 : Search & Destroy
- **Fonction `remove(string_of_words, caracter)`** : Supprime toutes les occurrences d'un caractère dans une chaîne.

### Partie 7 : Caedite eos. Novit enim Dominus qui sunt eius
- **Fonction `remove_many(string_of_words, caracters)`** : Supprime toutes les occurrences d'une série de caractères dans une chaîne.

### Partie 8 : Caesar (1/3, 2/3, 3/3)
- **Fonction `crypto(a_string, a_number)`** : Chiffre une chaîne de caractères avec le chiffrement de César.
- **Fonction `decrypt(a_string, a_number)`** : Déchiffre une chaîne de caractères avec le chiffrement de César.

### Partie 9 : Décrypter
- **Fonction `decrypt(a_string, a_number)`** : Déchiffre une chaîne de caractères avec le chiffrement de César (écrite sur une seule ligne).

### Partie 10 : Enigma
- **Fonction `enigma(crypted_string)`** : Aide à trouver la clé de chiffrement en testant tous les décalages possibles.
